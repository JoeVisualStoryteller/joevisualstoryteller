# Security Policy

## Supported versions

This repository is a single-page portfolio site. Only the version currently deployed from the `main` branch to https://joevisualstoryteller.github.io/joevisualstoryteller/ is supported. Fixes are made on `main` and deployed automatically; older commits are not patched.

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request.

1. Go to this repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Describe the issue, how to reproduce it, and its impact.

You can expect:

- **Acknowledgement** within 5 business days.
- **A status update** at least every 14 days while the report is open.
- **If accepted:** a fix deployed to the live site, a note in the advisory, and credit if you would like it.
- **If declined:** an explanation of why, for example if the issue is out of scope.

## Scope

In scope: this repository's source code, its GitHub Actions workflows, and the deployed site.

Out of scope: GitHub Pages and GitHub itself (report those to [GitHub](https://bounty.github.com/)), and issues that require a compromised device or browser.
